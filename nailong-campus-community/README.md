# 奶龙校园社区原型

## 参赛现场启动

在 PowerShell 中进入本目录并运行：

```powershell
.\Start-Competition-Demo.ps1
```

脚本会检查 Node.js 版本、确认默认端口 `5179` 可用、构建网页，并为本次演示创建独立的 SQLite 数据目录。每次启动会生成新的演示数据副本，不删除或覆盖 `data/campus.sqlite` 中已有的数据。服务运行期间请保持窗口打开，按 `Ctrl+C` 结束。

如果 `5179` 已由其他本机服务占用，可指定其他端口，例如 `.\Start-Competition-Demo.ps1 -Port 5279`。

启动后访问 `http://127.0.0.1:5179/`。如果 5179 端口已被占用，先关闭上一次演示服务，再重新启动。

## 开发模式

需要 Node.js 22.5 或更新版本（使用 Node 内置 SQLite，无需安装数据库服务）。

```powershell
npm install
npm run dev
```

开发模式同时启动 Vite 页面和本地 API。默认页面为 `http://127.0.0.1:5179`，API 为 `http://127.0.0.1:5180`；如果这些端口被其他程序占用，Vite 会自动切换端口。Vite `/api` 代理始终连接本机 5180 端口。

构建和生产模式：

```powershell
npm run build
npm start
```

生产服务默认监听 `127.0.0.1:5179`。要让同一局域网的设备访问，可在 PowerShell 中设置 `HOST=0.0.0.0` 后启动；这只开放给当前网络环境，不会自动把服务发布到互联网。正式公网部署需要可访问的 Node 主机、持久化磁盘和 HTTPS。

## 当前后端功能

- SQLite 保存演示账号、社区动态、点赞、评论、闲置商品和私信。
- 访客可以读取社区与集市；互动需要创建昵称演示账号。
- 同一服务中的已登录用户通过 Server-Sent Events 接收新动态、评论、集市条目、在线状态和私信更新。
- 私信以 HTTP-only、SameSite 会话 Cookie 识别用户，消息事件只发给会话双方。
- 地图角色位置、资料和社交状态通过 API 持久化；公开资料可出现在地图同学列表。

SQLite 默认文件位于 `data/campus.sqlite`，已加入 Git 忽略规则。可通过 `CAMPUS_DATA_DIR` 指定独立数据目录；参赛启动脚本会自动设置一次性目录。示例用户、动态和闲置商品只用于原型展示。

## 身份与部署边界

昵称演示账号不验证河海大学身份，不应称为校内认证。真实校内认证方式尚未确定。当前后端适合本机和局域网原型演示；公网部署前还需要配置域名与 HTTPS、备份策略、限流与内容审核，并确认学校认证接入方式。不要用演示账号处理真实身份、付款或交易数据。
